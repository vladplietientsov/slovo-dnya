# Слово дня 🎯

Гра типу [Contexto](https://contexto.me) / Semantle **українською**. Треба
вгадати загадане слово: після кожної спроби бачиш **позицію** — наскільки твоє
слово близьке за змістом до загаданого. Позиція `1` — вгадав.

Гра на одну спробу-загадку в день добре пасує для двох гравців у Telegram
(це наступний етап). Зараз готова **консольна версія**.

## Як це працює

Ніякої великої мовної моделі не треба — лише **word embeddings**: кожне слово
перетворюється на вектор, і слова зі схожим змістом опиняються поруч
(«кіт» близько до «собака», далеко від «податок»).

1. Беремо словник поширених слів (топ-15 000 із частотного списку).
2. Для загаданого слова рахуємо косинусну схожість кожного слова словника.
3. Сортуємо — виходить рейтинг. Позиція здогадки = скільки слів ближчі за неї.

Використовується spaCy-модель `uk_core_news_md`:
- **floret-вектори** — вектор має будь-яке слово, навіть якого немає в словнику;
- **лематизація** — «котів», «котові» зводяться до «кіт», тож форма не важлива.

Загадані слова (`data/secret_words.txt`) **вивірені вручну**: частотний список
зібраний із субтитрів і містить багато російських та сміттєвих слів, тож для
щоденного слова він не годиться.

## Встановлення

Потрібен Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
python build_data.py        # завантажить частотний список і збудує data/vocab.txt
```

## Гра

```bash
python play.py              # слово дня (однакове для всіх сьогодні)
python play.py --random     # випадкове слово
python play.py --word кіт   # конкретне слово (для тесту)
```

Кольори за позицією: 🟢 ≤100  🟡 ≤1000  🔴 далі. Команди: `/здатися`, `/вихід`.

## Telegram-бот

1. Створи бота через [@BotFather](https://t.me/BotFather), отримай токен.
2. Скопіюй `.env.example` у `.env` і встав туди токен (у репу `.env` не потрапляє):
   ```bash
   copy .env.example .env   # Windows
   # cp .env.example .env    # Linux/macOS
   ```
3. Заповни `SECRET_SALT` випадковим рядком
   (`python -c "import secrets; print(secrets.token_hex(32))"`) — без нього слово
   дня можна вирахувати з репозиторію.
4. Запусти:
   ```bash
   python bot.py
   ```
5. Бот закритий для сторонніх: кожен гравець пише боту `/start`, бот відповідає
   його Telegram ID. Впиши ID через кому в `ALLOWED_USERS` у `.env` і перезапусти бота.

Бот тримає одне спільне слово на день для всіх гравців. Пишеш слово — отримуєш
позицію й колір. Стан рахується за гравцем, тож грати можна і в приватному чаті,
і в групі. Команди: `/hint`, `/stats`, `/giveup`, `/newword`, `/help`.

- Нове слово з'являється опівночі (`TIMEZONE`, за замовч. `Europe/Kyiv`).
- Коли поточне слово вгадали двоє гравців, `/newword` відкриває наступний раунд
  з новим словом (слова за день не повторюються). Кожна перемога в раунді
  рахується в таблиці, а серія 🔥 — за днями.
- **Статистика**: перемоги, серії поспіль 🔥, найкраща кількість спроб, таблиця
  «хто попереду».
- Стан зберігається в `data/game.db` (SQLite, у репу не потрапляє) або в Turso
  на хостингу.

## Хостинг на Render (безкоштовно)

Бот живе на безкоштовному Render і не залежить від твого комп'ютера. Коли ніхто
не пише, сервер засинає. Перше повідомлення його будить, і відповідь іде
30–60 с, далі швидко. Статистика зберігається в безкоштовній базі
[Turso](https://turso.tech), бо диск Render стирається при кожному перезапуску.

1. **Turso**: зареєструйся на [turso.tech](https://turso.tech) → створи базу
   (регіон Frankfurt) → скопіюй її URL (`libsql://...`) і створи токен
   (Generate Token).
2. **Render**: New → Blueprint → вибери цей репозиторій. Render прочитає
   `render.yaml` і попросить ввести секрети: `TELEGRAM_BOT_TOKEN`,
   `SECRET_SALT`, `ALLOWED_USERS`, `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`.
   Значення бери з локального `.env`, а `SECRET_SALT` має бути той самий, щоб
   слово дня не змінилось.
3. Почекай, поки збірка завершиться (кілька хвилин), і напиши боту.

Бот сам реєструє вебхук у Telegram. Оновлення: `git push`, Render перезбере
бота автоматично.

> Локальний `python bot.py` без `WEBHOOK_URL` працює як раніше (опитує Telegram).
> Не запускай його одночасно з Render: запуск локально скасує вебхук, і
> тоді після зупинки локального бота треба перезапустити сервіс на Render.

## Структура

| Файл | Призначення |
|---|---|
| `engine.py` | рушій: вектори, лематизація, рейтинг, слово дня, підказки |
| `play.py` | консольна гра |
| `bot.py` | Telegram-бот |
| `storage.py` | SQLite або Turso: гравці, здогадки, результати, серії |
| `render.yaml` | опис сервісу для Render |
| `build_data.py` | завантаження частотного списку → `data/vocab.txt` |
| `data/secret_words.txt` | вивірений список слів для загадування |
| `test_engine.py` | перевірка адекватності позицій |
| `test_smoke.py` | перевірка логіки сховища й підказок |

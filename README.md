# Слово дня 🎯

Гра типу [Contexto](https://contexto.me) / Semantle **українською**. Треба
вгадати загадане слово: після кожної спроби бачиш **позицію** — наскільки твоє
слово близьке за змістом до загаданого. Позиція `1` — вгадав.

Гра на одну спробу-загадку в день добре пасує для двох гравців у Telegram
(це наступний етап). Зараз готова **консольна версія**.

## Як це працює

Ніякої великої мовної моделі не треба — лише **word embeddings**: кожне слово
перетворюється на вектор, і слова зі схожим змістом опиняються поруч
(«кіт» близько до «собака», далеко від «податок»).

1. Беремо словник поширених слів (топ-15 000 із частотного списку).
2. Для загаданого слова рахуємо косинусну схожість кожного слова словника.
3. Сортуємо — виходить рейтинг. Позиція здогадки = скільки слів ближчі за неї.

Використовується spaCy-модель `uk_core_news_md`:
- **floret-вектори** — вектор має будь-яке слово, навіть якого немає в словнику;
- **лематизація** — «котів», «котові» зводяться до «кіт», тож форма не важлива.

Загадані слова (`data/secret_words.txt`) **вивірені вручну**: частотний список
зібраний із субтитрів і містить багато російських та сміттєвих слів, тож для
щоденного слова він не годиться.

## Встановлення

Потрібен Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
python build_data.py        # завантажить частотний список і збудує data/vocab.txt
```

## Гра

```bash
python play.py              # слово дня (однакове для всіх сьогодні)
python play.py --random     # випадкове слово
python play.py --word кіт   # конкретне слово (для тесту)
```

Кольори за позицією: 🟢 ≤100  🟡 ≤1000  🔴 далі. Команди: `/здатися`, `/вихід`.

## Структура

| Файл | Призначення |
|---|---|
| `engine.py` | рушій: вектори, лематизація, рейтинг, слово дня |
| `play.py` | консольна гра |
| `build_data.py` | завантаження частотного списку → `data/vocab.txt` |
| `data/secret_words.txt` | вивірений список слів для загадування |
| `test_engine.py` | швидка перевірка адекватності позицій |

## Далі за планом
